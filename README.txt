Как выложить на GitHub Pages
1. Создайте репозиторий (например, milta), Public.
2. Add file > Upload files: загрузите index.html, manifest.webmanifest, icon-180.png, icon-512.png (и папку fonts, если есть шрифт).
3. Settings > Pages > Branch: main, папка / (root) > Save.
4. Через минуту сайт будет по адресу https://ВАШ-ЛОГИН.github.io/milta/
5. На iPhone: Safari > Поделиться > На экран «Домой».
Шрифт Adiabene: положите файл Adiabene.woff2 (или Adiabene.ttf) в папку fonts рядом с index.html.
